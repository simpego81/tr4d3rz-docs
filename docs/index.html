2.1 — Population

A population of individuals running in parallel.

Each individual is a complete system: ALU Box + evolutionary state machine with its own IIR parameters and intervention thresholds.

2.2 — Genome

The genome encodes every parameter of the individual.

IIR₁(P), IIR₂(P), IIR₁(V), IIR₂(V), Δmgn₁, Δmgn₂, ls_ax, ls_rule, ls_it — all packed in a colour-block chromosome.

2.3 — Life Cycle

One year of market data, stock by stock.

ENI · ENEL · GENERALI · UNIPOL — daily historical series at increasing speed (1x → 15x). CAGR computed per stock, then the individual's annual average is stored in the table.

2.4 — Parallelism

All individuals operate on the same stream.

The OHLCV stream is unique and shared. Each individual builds its own equity curve in parallel, applying its own IIR rules and margin thresholds.

2.5 — Selection

Fitness selection: only the best survive.

The CAGR table is sorted in descending order. Two arrows pick randomly among the top performers — the two parents of the next generation.

2.6 — Crossover

Genomes merge into a child.

Random segments from each parent combine — IIR₁ gene from Parent A, Δmgn₂ from Parent B, and so on. L-System rules recombine to shape a new growth topology.

2.7 — Mutation

A small stochastic perturbation.

One gene in the child genome is slightly perturbed. This introduces genetic variability that allows evolution to explore new predictive niches.

2.8 — Birth

The genome becomes an individual.

The new agent enters the simulation and begins its life cycle — competing for predictive niches with the previous generation.
